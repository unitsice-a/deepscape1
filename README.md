# 증권사 수수료 및 혜택 비교 대시보드

주식 투자를 시작한 대학생과 초보 투자자가 거래 조건에 따른 증권사별 예상 수수료를 비교하고, 선택에 필요한 정보를 쉽게 이해할 수 있도록 돕는 모바일 웹 프로토타입입니다.

## 2. PRD

### 2-1. 프로젝트 개요

| 항목 | 내용 |
| --- | --- |
| 프로젝트명 | 증권사 수수료 및 혜택 비교 대시보드 |
| 프로젝트 유형 | ③ AI 서비스 체험형 |
| 한 줄 정의 | 사용자의 거래 금액, 거래 횟수, 투자 방식 등을 바탕으로 증권사별 수수료와 혜택 정보를 비교하고 적합한 선택지를 찾도록 돕는 서비스 |
| 목표 사용자 | 소액 적립식 투자, 미국 주식 거래, 국내 배당주 투자 등에 관심이 있는 대학생 및 초보 개인 투자자 |
| 핵심 가치 | 여러 증권사의 비용과 혜택 정보를 한곳에서 확인하고, 자신의 거래 조건에 맞춰 예상 비용을 비교할 수 있도록 지원 |

### 2-2. 해결하려는 문제

- 증권사마다 거래 수수료율, 환율 우대, 이벤트 조건이 서로 다릅니다.
- 사용자는 각 증권사의 홈페이지나 앱을 따로 방문해 정보를 확인해야 합니다.
- 수수료율만으로는 실제 거래 조건에 따른 비용 차이를 쉽게 파악하기 어렵습니다.
- 초보 투자자는 여러 조건을 직접 비교하고 계산하는 과정에서 어려움을 겪을 수 있습니다.

**제공 가치:** 거래 조건에 따른 예상 수수료와 증권사별 정보를 한 화면에서 비교하여 정보 탐색에 드는 시간과 계산 부담을 줄입니다.

### 2-3. 핵심 사용자 및 유저스토리

| 사용자 | 필요한 기능 | 기대 결과 |
| --- | --- | --- |
| 주식 투자를 시작한 초보자 | 거래 금액과 거래 횟수 입력 | 자신의 거래 조건을 비교에 반영할 수 있음 |
| 수수료를 줄이고 싶은 투자자 | 증권사별 예상 수수료 계산 및 비교 | 증권사별 비용 차이를 한눈에 확인할 수 있음 |
| 비교 결과를 쉽게 이해하고 싶은 사용자 | 결과와 계산 근거에 대한 쉬운 설명 | 수수료 차이가 발생한 이유를 이해할 수 있음 |

### 2-4. MVP 범위

**포함 기능 (Must Have)**

1. 거래 금액 입력
2. 입력 금액과 설정된 수수료율을 이용한 증권사별 예상 수수료 계산
3. 증권사별 예상 수수료 비교 결과 표시
4. 비교 결과와 비용 차이에 대한 쉬운 설명 제공

**추가 고려 기능 (Could Have)**

- 증권사별 이벤트 및 혜택 정보 확인
- 환율 우대 조건 비교

**이번 프로젝트에서 제외 (Won't Have This Time)**

- 실제 증권사 데이터의 실시간 자동 연동
- 회원가입 및 로그인
- 비교 결과 저장
- 실제 주식 매매 또는 사용자의 자산 관리·거래 실행
- 수익률 보장이나 특정 주식 매수 권유

> 프로젝트의 전체 아이디어에는 수수료·환율 우대·이벤트 혜택 비교가 포함되지만, 9주차 PRD에서 정의한 초기 MVP는 거래 금액 입력과 예상 수수료 계산·비교에 집중합니다. 추가 혜택 비교는 초기 MVP 범위와 구분합니다.

### 2-5. 화면 구조 (IA)

| 화면 ID | 화면명 | 주요 콘텐츠 및 기능 |
| --- | --- | --- |
| S-01 | 거래 조건 입력 | 거래 금액 입력, 입력값 확인, 비교하기 |
| S-02 | 수수료 비교 결과 | 증권사별 예상 수수료 표, 비용 차이 및 결과 설명 |

현재 저장소의 모바일 프로토타입은 위 핵심 흐름을 바탕으로 홈, 수수료 비교, 증권사 정보 등의 화면을 시연할 수 있도록 구성되어 있습니다. 프로토타입에 추가된 로그인·마이페이지 등은 시연용 화면이며, PRD의 초기 MVP 필수 범위에 포함된 기능은 아닙니다.

### 2-6. 사용자 이용 흐름

**정상 흐름**

거래 금액 입력 → 비교하기 선택 → 증권사별 예상 수수료 계산 → 비교 결과 확인 → 결과 설명 확인

**예외 흐름**

- 거래 금액을 입력하지 않은 경우: 금액 입력 안내를 표시합니다.
- 0 이하 또는 잘못된 금액을 입력한 경우: 올바른 금액을 입력하도록 안내합니다.
- 계산 결과가 표시되지 않는 경우: 오류 안내 후 다시 시도할 수 있도록 합니다.
- 거래 조건을 바꾸려는 경우: 입력 화면으로 돌아가 금액을 수정한 뒤 다시 비교합니다.

### 2-7. 기능 요구사항

| 기능 | 입력 | 처리 | 결과 | 완료 조건 |
| --- | --- | --- | --- | --- |
| 거래 금액 입력 | 거래 금액 | 입력값 확인 | 입력한 거래 금액 | 금액을 입력하고 수정할 수 있음 |
| 예상 수수료 계산 | 거래 금액, 증권사별 예시 수수료율 | 정해진 계산식으로 계산 | 증권사별 예상 수수료 | 설정된 수수료율에 맞게 계산됨 |
| 수수료 비교 | 증권사별 계산 결과 | 금액 기준으로 결과 정리 | 비교 표 | 증권사별 비용과 차이를 확인할 수 있음 |
| 결과 설명 | 비교 결과 | 비용 차이와 계산 결과를 쉬운 문장으로 정리 | 비교 결과 설명 | 초보 사용자도 결과를 이해할 수 있음 |

### 2-8. AI와 사람의 역할

- **AI의 역할:** 증권사 정보 정리, 비교 결과 요약, 수수료 차이와 혜택 조건에 대한 쉬운 설명을 보조합니다.
- **서비스의 계산 역할:** 예상 수수료는 정해진 산술식으로 계산합니다. 계산 결과를 AI가 임의로 결정하지 않습니다.
- **사람의 역할:** 수수료율과 혜택 정보를 확인하고, 계산 결과 및 AI 설명이 근거와 일치하는지 검토합니다.

### 2-9. 데이터 및 정확성 기준

- 초기 프로토타입에서는 가상의 증권사 수수료율 또는 설명을 위한 예시 데이터를 사용할 수 있습니다.
- 예시 데이터는 실제 증권사의 현재 수수료나 혜택을 의미하지 않습니다.
- 실제 데이터를 적용할 경우 각 증권사의 공식 홈페이지 및 수수료 안내 자료를 확인합니다.
- 수수료와 이벤트 조건은 변경될 수 있으므로 출처와 확인 기준일을 표시해야 합니다.
- 환율 우대 및 이벤트는 대상 고객, 신청 여부, 적용 기간 등 조건을 함께 확인해야 합니다.
- 예상 수수료는 실제 청구 금액과 다를 수 있으므로 최종 조건은 해당 증권사의 공식 안내를 통해 확인해야 합니다.

### 2-10. 테스트 방법 및 성공 기준

**테스트 방법**

1. 주식 투자 경험이 적은 대학생 3~5명을 대상으로 프로토타입을 사용하게 합니다.
2. 거래 금액을 입력하고 증권사별 수수료를 비교하도록 합니다.
3. 비교 결과와 비용 차이를 이해할 수 있는지 확인합니다.
4. 입력 과정에서 어려움이 있는지, 결과가 증권사 비교에 도움이 되는지 의견을 수집합니다.

**성공 기준 (목표)**

- 사용자가 거래 금액을 입력하고 비교 결과를 확인할 수 있습니다.
- 동일한 입력값에 대해 수수료 계산 결과가 일관되게 나타납니다.
- 사용자가 증권사별 비용 차이와 계산 근거를 이해할 수 있습니다.
- 테스트 참여자의 80% 이상이 서비스가 증권사 비교에 도움이 된다고 평가하는 것을 목표로 합니다.

> 위 수치는 프로젝트의 테스트 목표이며, 실제 사용자 테스트를 통해 확인된 결과가 아닙니다.

### 2-11. 위험 요소 및 대응

| 위험 요소 | 대응 방법 |
| --- | --- |
| 수수료·이벤트 정보의 최신성 | 공식 출처와 확인 기준일을 표시하고 변경 여부를 확인합니다. |
| 계산 오류 | 정해진 계산식으로 산출하고 별도 계산으로 결과를 검증합니다. |
| 환율 우대 조건 오해 | 우대율뿐 아니라 적용 조건과 실제 환전 비용 확인 필요성을 함께 안내합니다. |
| 이벤트 적용 조건 누락 | 신규 고객 여부, 이벤트 신청 여부, 적용 기간 등을 표시합니다. |
| 생성형 AI의 부정확한 설명 | AI가 정리한 내용을 공식 자료 및 계산 결과와 대조합니다. |
| 비교 결과에 대한 과도한 신뢰 | 비교 기준과 한계를 표시하고, 최종 조건은 증권사 공식 정보를 확인하도록 안내합니다. |
